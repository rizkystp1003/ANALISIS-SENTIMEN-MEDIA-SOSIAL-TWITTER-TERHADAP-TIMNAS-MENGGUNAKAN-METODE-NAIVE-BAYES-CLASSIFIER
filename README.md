# 🧠 Analisis Sentimen Media Sosial Twitter terhadap Timnas Menggunakan Metode Naive Bayes Classifier

Repositori ini berisi proyek dengan judul **"Analisis Sentimen Media Sosial Twitter terhadap Timnas Menggunakan Metode Naive Bayes Classifier"**.  
Proyek ini bertujuan untuk mengklasifikasikan opini masyarakat di media sosial menjadi dua sentimen: **positif** dan **negatif**.

Metode yang digunakan adalah **Naive Bayes Classifier**, salah satu algoritma klasifikasi berbasis probabilistik yang umum digunakan dalam pemrosesan bahasa alami (NLP).

---

## 📌 Fitur Utama

- Preprocessing teks: case folding, cleansing, tokenizing, stopword removal, dan stemming.
- Labeling untuk data latih.
- TF-IDF
- Pelatihan model Naive Bayes untuk klasifikasi sentimen.
- Evaluasi model menggunakan metrik akurasi, presisi, dan recall.
- Visualisasi hasil analisis dalam bentuk Confusion matrix, Bar chart, Wordcloud.

---
